# زخرفة أسماء

Arabic-first Unicode name decorator. The tool runs in the browser. Results are text, not images.

## Commands

```bash
npm install
npm test
npm run dev
npm run build
```

## Domain

Set `SITE_URL` before a production build, for example `https://example.com`. Canonical links, hreflang, and the sitemap are emitted only when that variable is set. `robots.txt` is already public.

About and contact stay without an invented owner name or email until the real ones exist.
